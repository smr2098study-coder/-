# 格式来源与参数

来源：用户提供的《师门_word ppt的一般格式.docx》，Word部分“正文部分”“标题部分”“表格及图片”。以下采用文字要求，而不是复制说明文件自身的显示格式。原文件未随公开技能包分发。

正文和标题的英文及数字为 Times New Roman。表内及题注原文仅规定黑体；本技能补充英文数字也用 Times New Roman，可被任务要求覆盖。表格和图片整体居中；原文没有规定表格每个单元格的水平对齐。

## 补充默认值（不是师门原文要求）

新建无模板文档：A4，四边页边距2.54 cm，黑色文字，正文两端对齐，段前段后0；标题左对齐、1.5倍行距、段前6 pt、段后0；文档总标题居中、宋体三号加粗且无首行缩进。表内正文不加粗、无首行缩进；表图题居中、不加粗、1.15倍行距、无首行缩进。基础表格用细黑色网格线；特殊三线表、表头加粗或跨页重复表头按实际需要设置。原文没有强制这些边距、颜色、边框和段落间距。

用户最新明确要求优先于本节旧版默认值：正文、标题、表图题注均不启用 `keepNext`、`keepLines`、`pageBreakBefore`，同时清理直接格式、样式和文档默认值中的节点。正文及标题不保留 `numPr`，不用列表样式，编号必须为普通文字。真正需要章节换页时插入实际分页符，不使用“段前分页”属性。孤行控制不在本次三项清理范围内。

已有文档保留页面和封面设计，除非用户要求统一。不以通用设计规范覆盖本技能的字号、字体或标题缩进。

## OOXML 实现

- 字体：`w:rFonts` 的 `eastAsia` 设置宋体/黑体，`ascii`、`hAnsi`、`cs` 设置 Times New Roman；清除同一作用域的主题字体属性。审查字符样式和直接格式是否覆盖段落样式；缺少直接字体不等于缺少字体，应解析继承。
- 字号：半点单位，三号32、小三30、四号28、小四24、五号21，同时检查 `sz` 与 `szCs`。
- 首行2字符：`w:ind w:firstLineChars="200"`。字符单位以百分之一字符计；`firstLine` 作为兼容回退可用对应字号的两倍（例如12 pt正文为480 twip），不要把480 twip当作所有字号的2字符。清除冲突的悬挂和左右字符缩进。
- 1.5倍：`w:spacing w:line="360" w:lineRule="auto"`；1.15倍为276。段落应关闭与文档网格对齐 `snapToGrid=false`，避免名义行距被网格改变。
- Heading 1–5分别用大纲级别0–4，按各自字号和缩进设置，下一段样式为正文；样式自身必须清除三项分页属性和 `numPr`。章节编号只使用显式文字，禁止多级自动编号。
- 正文不用 `List Bullet`、`List Number` 等列表样式，清除 `numPr` 及继承源，包括 `numId=0`。仅清理旧文档时不删除其文字和参考文献序号；现有可见自动序号需先准确转为普通文字。

以上普通文字编号要求针对章节编号和段落列表，不包括原生脚注/尾注及NOTEREF。引用模式A/B遵循[引用规范](citation-modes.md)：A每次引用独立真实脚注；B保留真实尾注编号与可更新交叉引用，尾注区baseline标记和悬挂缩进优先于正文格式。
